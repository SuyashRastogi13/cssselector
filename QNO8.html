CSS Selectors & Background Images

Every rule below is defined once in <style>, then activated in the body by tag, class, or id.

Element selector

This paragraph is styled purely by the plain element selector written for p — no class or id needed at all.

Class selector

This paragraph uses the class selector .highlight, switched on here with class="highlight".

Element With Its Own Background Image

This box is styled by the id selector #special-box, and it carries a completely different background image from the page itself. This paragraph is also styled by a separate descendant selector, #special-box p, which only affects paragraphs inside this box.

Combined selector

This note is styled by p.note — a combined selector that only matches <p> tags carrying the class "note".

Pseudo-class selector

Hover over this button — its color change comes from .hover-box:hover, a rule that only activates on mouse-over.

Selector Reference

Selector Type Applies To
body, h1, p Element Every matching tag on the page
.highlight Class Any tag with class="highlight"
#special-box ID The single element with id="special-box"
#special-box p Descendant Only <p> tags nested inside #special-box
p.note Combined <p> tags that also carry class "note"
h2, .highlight, #special-box h2 Group All three selectors at once, in one rule
.hover-box:hover Pseudo-class Only while the mouse hovers over the element
